# Settings

| Setting | Default | What it does |
| --- | --- | --- |
| **Poll Interval Seconds** | 240 | How often usage limits refresh for each account (minimum 180). |
| **Warn Threshold Percent** | 80 | Usage at which a bar turns red. Bars turn yellow at three quarters of it. |
| **Auto Reload After Switch** | off | Reload the window right after a switch instead of asking first. |
| **Claude Command** | `claude` | CLI used for logins and Say Hi. Use the full path if VS Code can't find it. |
| **Say Hi Model** | `haiku` | Model for Say Hi warmups. |
| **Say Hi Prompt** | `Hi` | Prompt sent by Say Hi. |
| **Say Hi Timeout Seconds** | 120 | How long a warmup may run. |
| **Credentials Path** | *(empty)* | Custom `.credentials.json` location. Empty means `~/.claude/.credentials.json`. |

You can reopen this guide any time with **Claude: Getting started** from the Command Palette or the panel's **⋯** menu.
